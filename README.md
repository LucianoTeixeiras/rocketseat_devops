## 📌 Sobre o Curso

A formação DevOps da Rocketseat tem como objetivo capacitar profissionais para atuarem com automação, provisionamento de infraestrutura, integração contínua, entrega contínua, monitoramento e escalabilidade de aplicações modernas.

---

## 🛠️ Tecnologias e Ferramentas

Durante o curso, são abordadas diversas tecnologias:

- Docker & Docker Compose
- Kubernetes
- GitHub Actions (CI/CD)
- Terraform
- Prometheus & Grafana
- NGINX & Apache
- Node.js para aplicações exemplo
- AWS (EC2, S3, IAM, RDS, EKS)
- Git & GitHub
